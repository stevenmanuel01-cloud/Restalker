# Restalker

## Get the phone app (Android)
1. On your Android phone, open **[the newest Restalker Mobile](https://github.com/stevenmanuel01-cloud/Restalker/releases/latest)** and tap the `.apk` file under *Assets*.
2. Open the downloaded file and tap **Install** (Android may ask you to allow installs from your browser once).
3. Open Restalker. After that it updates itself.

## Get the PC program (Windows)
Ask someone who has it: in Restalker, **Copy** &rarr; *Download the copy for a new user*. Unzip it and start Restalker.

# Restalker

Releases of Restalker (program files only). Each copy of Restalker checks `latest.json` here and offers the update with one click.
An update replaces program files only - never a user's products, settings, sign-ins or purchases.
